A real native capture

Generator seed 42, sample 0. This bundle was rendered by Triage’s native headless capture command, not produced by the website or an image mockup.

Download the sample

  • Realized scene JSON — replay without running the generator.
  • Metadata JSON — camera calibration, identities, semantic ontology and output formats.
  • sRGB color PNG and linear RGBA8 raw color.
  • Optical-Z depth — float32 little-endian metres, not Euclidean range.
  • Instance IDs and semantic classes — uint32 little-endian.
  • Diagnostic panel preview — display colors and annotations, not training labels.

Color originates from a clipped, quantized linear RGBA8 attachment; sRGB conversion does not recover HDR detail. Background ID/class is 0; ground is class 1, gate 2, obstacle 3. Each gate’s three boxes share one instance ID. World coordinates are right-handed Y-up in metres; optical coordinates are X-right, Y-down, Z-forward.

Replay locally

From the repository root, inside nix develop:

cargo run -p render-smoke -- --inspect \
  --scene examples/seed-42-sample-0/scene.json \
  --output target/example-replay --verify

Exact scene data is reproducible. Pixel-identical rendering across different GPU devices/backends is not promised. This example demonstrates generation and labelled capture, not measured sim-to-real improvement.
