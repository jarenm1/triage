Reproducible by construction

The versioned recipe records seed, sample index and bounded variation settings. Realized JSON stores every world-space box, color, ID and sensor calibration. Reproduce a scene rather than inferring geometry from a screenshot.

Right-handed world: Y up, metres. Optical camera: X right, Y down, Z forward. Depth is optical-axis Z in metres, not Euclidean range.

The native example includes its calibrated sensor. Live rendering retains recipe resolution when the canvas resizes; orbit and zoom change the camera, not the geometry.

Keyboard and pointer controls

Focus the canvas. 1–4: RGB / depth / IDs / compare. S: return to generated showcase. Drag or arrows: orbit. Scroll or pinch: zoom. R or double-click: reset camera. Right-click: next output.

Space: play/pause recording or toggle showcase auto-orbit. C: mounted/orbit camera. N: next vehicle. [ / ]: seek one second. Home: restart recording. Reduced-motion preferences disable automatic motion on startup.

A rendering tool, not a reality claim

RGB sensor bytes are linear LDR; the browser and PNG previews use sRGB display encoding. Do not compare raw byte values directly with a displayed screenshot. Depth colors are normalized to the visible range; they are not metric depth data. Palette colors are visualizations, not label values.

This bounded, synthetic box family does not model realistic materials, optics, sensor noise or scene diversity. It makes no sim-to-real or trained-policy performance claims. Shared scene generation is deterministic; exact rendered pixels can vary between GPU backends.

Download the native seed 42 / sample 0 example for actual RGB, metric depth, labels and calibration. A scene JSON download is geometry and camera state, not a sensor capture.
